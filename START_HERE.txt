CodyNick Portal 3.20.0
Run the standard setup/update command from an interactive terminal on the VPS:

wget -4 -O /tmp/codynick-browser-setup.sh "https://raw.githubusercontent.com/codynick/platform-server-browser-upload/main/setup.sh?$(date +%s)" && sudo bash /tmp/codynick-browser-setup.sh

If no admin is configured, enter the exact first admin CodyNick ID when asked.
On a fresh installation it is reserved for matching CAS sign-in; no password or login session is created. Existing admins are retained without prompting.
For unattended setup: sudo env CODYNICK_ADMIN_ID='actual-id' bash /tmp/codynick-browser-setup.sh
Close CodyNick tabs before updating. Reopen and Ctrl+F5 afterward. Keep the printed website/account rollback commands; private projects are retained.

CodyNick Portal 3.19.0 — NUMBERED ZONE EXAMPLES

ONE COMMAND (fresh install or upgrade on Debian/Ubuntu VPS):

wget -4 -O /tmp/codynick-browser-setup.sh "https://raw.githubusercontent.com/codynick/platform-server-browser-upload/main/setup.sh?$(date +%s)" && sudo bash /tmp/codynick-browser-setup.sh

The installer reuses saved domain/CAS settings, backs up the website and updates
the existing account service. No firmware/backend/schema change is introduced.
Close old tabs, reopen /blocks/ and hard-refresh after installation.
Use the exact rollback paths printed by setup.sh for the website/account service.

The first fifteen Examples choices cover every combination of HW, Sim, Dash and
Sprite. Each complete .codynick archive contains both programs and panel settings.
The twelve existing examples remain available after the numbered collection.
See blocks/examples/ZONE_EXAMPLES.md for hardware requirements and expected results.
Start with 2, 3, 4, 8, 9, 10 and 14 (no CJP); then connect a CJP for the others.
