CodyNick Platform 3.21.0

Upgrade the existing server using the normal setup.sh command in README.md.
Community and Publish are on the toolbar; File > My published projects opens
publication management. Sign in/account is the rightmost header control.
Admin Panel includes persistent default runtime and cooldown controls.

Website/account backups and rollback paths are printed during setup.
Existing private projects, publications, configuration and per-user limits remain.
This release does not upload or change device firmware during server setup.
