CodyNick Portal 3.12.0 — CUMULATIVE GITHUB UPGRADE

Run this one command on your Debian/Ubuntu VPS:

wget -4 -O /tmp/codynick-browser-setup.sh "https://raw.githubusercontent.com/codynick/platform-server-browser-upload/main/setup.sh?$(date +%s)" && sudo bash /tmp/codynick-browser-setup.sh

It installs/updates the complete release from codynick/platform-server-browser-upload
on main, reusing the saved domain and existing CAS settings/private projects.
Includes all firmware, browser Python, dashboard and interface updates through pilot.6.
Close old editor/dashboard tabs, reopen /blocks/ and press Ctrl+F5 after upgrading.

The installer prints website and CAS backup paths and their rollback commands.
Use those printed commands for rolling back a GitHub setup/upgrade.
For a manual ZIP update, the previous update-local.sh workflow remains available.
Its convenience rollback script applies to the most recent manual ZIP update.

Python account Save/Load remains unavailable. Physical Python CJP/Android
validation is pending. The browser needs Internet for uncached Pyodide downloads.
See README.md for revision history and PYTHON_PILOT.md for Python testing.
