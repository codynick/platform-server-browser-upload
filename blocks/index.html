Use desktop Chrome. Close other applications using the CJP serial port.
Linux USB setup
On Ubuntu/Kubuntu, your account normally needs dialout membership to access the CJP serial port.
Run this on the Linux computer connected to the CJP—not on the VPS.
sudo usermod -aG dialout "$USER"
Then fully log out of your desktop and log back in. Closing the terminal or refreshing the page is not enough. Reopen Chrome and reconnect.
Close Arduino Serial Monitor, serial terminals, and other tabs using the device. If opening still fails, check:
ls -l /dev/ttyUSB0
id -nG
sudo fuser -v /dev/ttyUSB0
Replace ttyUSB0 if your selected device has a different name. These instructions apply to Ubuntu/Kubuntu; other Linux distributions may use a different serial-access group. Browser sandbox restrictions can also prevent access.
The website cannot change these operating-system permissions for you.
