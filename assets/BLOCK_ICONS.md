# Block header icon

`codynick-block-icon.png` is the transparent CodyNick mark used at 32 × 22 CSS pixels by `blocks/block-icons.js`. It decorates statement/event headers; inline value/reporters and shadows stay plain. The field is not serialized into project data.

The user supplied the original ICO. Its opaque white background was removed with the built-in image generation background-extraction tool at the user's request. The generated alpha channel is preserved. The icon is deployed and backed up by `install.sh` and restored by `rollback.sh`.
